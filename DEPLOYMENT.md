## How It Works

### Local Usage (Your Machine)

```bash
# 1. Setup
cd backend
pip install -r requirements.txt

# 2. Configure .env
# SPOTIFY_CLIENT_ID=...
# SPOTIFY_CLIENT_SECRET=...
# SPOTIFY_REDIRECT_URI=http://localhost:8888/callback
# OLLAMA_HOST=http://your-machine:11434
# OLLAMA_MODEL=qwen2.5:7b

# 3. Run
python playlist_updater.py

# This generates/updates:
# - ../data/history.json (history of all runs)
# - ../logs/run_*.log
```

### Vercel Dashboard

1. Open https://spotify-ai-playlist-three.vercel.app
2. Dashboard attempts to load `../data/history.json`
3. If data exists (manually synced), displays:
   - Current mood, energy, taste profile
   - Historical charts
   - Top artists, genres, energy distribution

## Troubleshooting

**Dashboard shows "No runs yet"**
→ Run `python playlist_updater.py` locally first to generate `data/history.json`

**Spotify OAuth error**
→ Clear `.spotify_cache` and verify credentials in `.env`

**Ollama connection failed**
→ Ensure Ollama is running: `ollama serve`
→ Check `OLLAMA_HOST` matches your setup

**GitHub Actions failing**
→ Check Actions tab at https://github.com/a-r-a-n/OllamaPlaylist/actions
